О библиотеке

Utilib предоставляет набор полезных функций и классов для C++, которые упрощают разработку.

Простота

Чистый и понятный API без лишних зависимостей

Практичность

Функции для работы со строками, файлами, математикой и другими повседневными задачами

Header-only

Просто подключите заголовочные файлы и используйте

Быстрый старт

#include <iostream>
#include "utilib/string_utils.hpp"

int main() {
    std::string s = "hello world";
    std::cout << utl::to_upper(s) << std::endl;  // HELLO WORLD
    return 0;
}
