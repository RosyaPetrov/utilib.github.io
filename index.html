// C++ UTILITY LIBRARY

> ОБЗОР

Utilib++ — это коллекция полезных инструментов для C++ разработчиков.

Версия: 1.0.0

Лицензия: MIT

#include "utilib/string_utils.hpp"

int main() {
    std::string s = "hello";
    std::cout << utl::to_upper(s); // HELLO
    return 0;
}

  • split/join

  • read_file
  • write_file
  • file_exists
